# Cross-jurisdiction topic notes

Notes here are things worth remembering regardless of which project triggered them, because
they recur: an adoption-by-reference chain, a rule of thumb that shows up in many
jurisdictions, a source that is reliably the fastest path to the primary text for a given
kind of question.

Suggested frontmatter for each `<topic-slug>.md`:

```
---
topic: Commercial food service health code adoption chains
last_verified: YYYY-MM-DD
---
```

Example entries to start once real research produces them:

- `ada-remodel-threshold.md` — the "percent of assessed value spent on alterations
  triggers a full accessibility upgrade" rule, and how it is phrased/thresholded
  differently across the states and model codes UNITE Ideas works in.
- `food-code-adoption-chains.md` — which counties/states adopt the FDA Food Code by
  reference, which edition, and any local amendments layered on top (e.g. hand-wash sink
  requirements that a county has NOT waived even where a hand sanitizer station might seem
  like an equivalent).
